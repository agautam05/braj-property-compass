# Braj Property Compass

Create a complete premium real-estate website and functional demo CRM for BrajProperty.in, “Property in Vrindavan”, serving Mathura and Vrindavan. Use a refined luxury Indian real-estate visual identity: warm ivory, deep navy, restrained muted gold, elegant serif headings, clean sans-serif body, strong premium residential/township photography, subtle motion, excellent responsive mobile design. Do not make it look like a religious tourism site or generic template.

Business projects and supplied locations:
1 Banke Bihari Orchid — Behind Aggarwal Restaurant, Mathura.
2 Banke Bihari Dham — Rukmani Vihar, Vrindavan.
3 Braj Anand Vatika — Satoha–Naugaon Road, Mathura.
4 Banke Bihari Kunj — Ramtal, Jait Road, Vrindavan.
5 Braj Lotus Greens — Mathura–Govardhan Road.
6 Banke Bihari Greens — Opposite Char Dham Temple, Vrindavan.
The poster advertises an overall range ₹15 lakh–₹2 crore and plot sizes 60–500 sq yd. Show only as indicative business-wide ranges, not project-specific prices, and say confirm current price/availability. Call number +91 96908 77877; WhatsApp +91 93067 22034. Make both editable in admin. MVDA approval, freehold and 5–10g gold offer claims in poster are unverified: do not publish as facts or active offers. Include disclaimer that approval/title/ownership and promotional terms require document verification. No return promises, invented amenities/distances, fake testimonials, invented business history or credentials.

Build all public routes fully:
Home with sticky header, hero, Hindi headline “अपने सपनों की प्रॉपर्टी, अब ब्रज की पावन भूमि पर।”, functional quick search, highlights, six project cards, locations, why choose, process, gallery, FAQs, enquiry CTA and footer.
Projects listing with working search, filters by location/type/budget/size, sorting, grid/list toggle and clear filters.
Six unique project detail pages with image gallery, supplied location, overview, information/specifications, enquiry-based pricing, map links to broad locality, prefilled enquiry form, site visit CTA, WhatsApp CTA and printable/downloadable brochure.
Project comparison for up to three projects, persistent while navigating.
About, Gallery with working category filters/lightbox, Contact with working enquiry and site visit forms, Privacy and Terms starter pages, responsive navigation, SEO metadata, accessible controls and 404 page.

All CTAs must work. Forms validate, show feedback and persist submissions so they appear in admin. WhatsApp wa.me links contain contextual prefilled messages; call uses tel:. Quick search, comparison, filters, FAQ accordion, gallery lightbox and brochure actions must work. Use realistic Indian formatting.

Build /admin as a polished DEMO MODE dashboard (not production-secure authentication) with an explicit Enter Demo Dashboard button. Sidebar: Overview, Projects, Inventory, Leads, Site Visits, Offers, Gallery, Website Content, Settings. Dashboard cards and charts seeded with sample data. Implement working CRUD for projects and inventory; lead search/filter/status pipeline/notes/CSV export; site visit management; offer management (gold offer inactive draft pending client verification); gallery management; editable website copy/FAQs; editable contacts and settings. Persist changes and form submissions in Supabase if configured, otherwise local persistence with clear demo-mode indication. Add reset demo data with confirmation. Seed fictional clearly-labelled demo leads, site visits and sample inventory; no fake customer data or actual availability claims. Never imply sample inventory is real.

Use illustrative property imagery and label it illustrative until real client photographs are supplied. Do not invent exact office address, project-specific pricing, plot inventory, amenities, distances, approvals or testimonials. Show “details available on enquiry” where information is missing. Make project content editable in admin. Build every route and functional flow, inspect responsiveness and fix errors before finishing.
